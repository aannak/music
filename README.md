# Music Streaming Database Spotify

**Команда:** Кожан Анна, Кучинская Лилиана, Юреня Дарья, Якименко Дарья
**Тема проекта:** База данных музыкального стримингового сервиса Spotify
**ER-диаграмма:** https://drawsql.app/teams/annaak/diagrams/spotify

## Описание
База данных содержит информацию о пользователях, артистах, альбомах, треках, плейлистах и прослушиваниях.

## Файлы
- `schema.sql` — создание таблиц
- `seed.sql` — наполнение тестовыми данными
